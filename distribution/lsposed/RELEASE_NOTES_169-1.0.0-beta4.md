# AA Experiments 1.0.0-beta4

The first catalog release adds Android Auto experiment discovery, typed overrides, optional Advanced controls, read-only diagnostics, large JSON/CSV export, and exact-build backup and recovery.

The module uses modern libxposed API 101 and is scoped to Android Auto (`com.google.android.projection.gearhead`). Android 8.1+ is required. It does not modify or redistribute Android Auto.

**Safety:** Advanced values require explicit confirmation, and effective getter overrides do not guarantee downstream head-unit or server behavior. Make a backup before changing settings. Use only when parked.
